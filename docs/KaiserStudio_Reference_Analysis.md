# KaiserStudio 参考程序逐页分析

本文基于参考版 `KaiserStudio.exe` 的 Windows UI Automation 控件树、
`.NET` 程序集 IL、`ErrorCode.XML`、`Paraters.txt` 和 `image/` 示意图整理。
“确认”表示由控件文本、事件命令或资源内容直接支持；未确认的语义不会作为
自动写入设备的依据。

## 1. 总体界面

- 主窗口默认最大化，顶部实时显示位置、多圈位置、单圈位置、速度、电流和母线电压。
- 顶部工具条显示 `Offline`、`Disabled`、`FLT`、`War`、`Refresh`、监视参数和驱动模式。
- 左侧“系统功能”是可滚动导航栏，中央是 MDI 文档式工作区。
- 常用交互是单元格回车提交或页面按钮提交，成功后以“设置成功”提示。
- 连接后先发送握手和监视配置，再由心跳维持数据。

## 2. 连接

- 字段：端口、波特率、数据位、校验位、停止位。
- 默认串口参数为 `115200 / 8 / None / 1`。
- 连接后进入实时监视状态，并提供驱动使能、故障复位和监视参数切换。
- 当前 Qt 版已实现串口枚举、握手、100 ms 心跳、断开和监视参数切换。

## 3. 驱动器信息

- 页面用于设置驱动器输入电压和电流传感器规格。
- 参考选项包括 `220V/5A`、`220V/20A`、`220V/30A`、`220V/50A`、
  `48V/20A`、`48V/30A`、`48V/50A`、`48V/100A`、
  `24V/20A`、`24V/30A`、`24V/50A`、`24V/100A`。
- 页面事件写入 `Pn021` 对应型号/传感器设定。
- 需要显示的信息还包括控制模式、显示模式、标定 K/B 和质量补偿。

## 4. 参数设定

- 使用高密度参数网格，每行六组 `Pn / Value`，共 12 列。
- 按钮语义为“从驱动器加载”“写入驱动器”“参数存储”。
- 修改后提示“参数写入成功，驱动器重新上电生效”。
- 参考版允许导出/导入 `.txt` 参数文件。
- 当前 Qt 版保留六组并排网格和详细表格，并扩展了 CSV、搜索、脏数据标记和写入确认。

### 已确认的参数

| 参数 | 含义 | 备注 |
|---|---|---|
| `Pn002` | 数显屏显示模式 | `79` 为力/转矩反馈，`81` 为位移量 |
| `Pn020` | 再生电阻投入电压阈值 | 与 Er020 处理直接相关 |
| `Pn025` | 制动器稳态保持电压 | 制动保持阶段 |
| `Pn026` | 制动器控制电压 | 动作/释放阶段 |
| `Pn044` | 目标设定力 | EHA 既有协议 |
| `Pn058/Pn059` | 电机每转指令脉冲数高/低四位 | 位置齿轮模式 |
| `Pn080` | 电机极对数 | 与铭牌一致 |
| `Pn085` | 电机额定电流 | 原始值 × 0.01 A |
| `Pn091/Pn092` | 瞬时/长时过载保护倍数 | Er006/Er005 检查项 |
| `Pn130` | 电机转速限定 | Er014/Er015 检查项 |
| `Pn151` | 制动器控制类型 | 0 正常，1 强制松开，2 强制闭合 |

## 5. 电机

- 电机额定电流：`Pn085`，显示值按原始值 × 0.01。
- 电机极对数：`Pn080`，单位“对”。
- 设置错误可能导致方向异常、过载报警或转矩能力不匹配。

## 6. 反馈

页面包含三类内容：

1. 编码器类型：支持 Nikon、Tamagawa、Biss-C 和多组增量式编码器；
   单圈分辨率包括 17/18/19/20/21/22/23/24 bit，多圈位包括 0 bit 或 16 bit。
2. 位置处理：位置清零、绝对位置清零、磁极检测、检测旋转时间、检测频率、
   检测锁轴电压。
3. 等价编码器输出：无脉冲、AB 正交、双脉冲、脉冲+方向；
   每圈输出脉冲数由高低两个参数组合。

重要提示：

- 修改编码器类型后重新上电生效。
- 位置清零只允许在下使能状态执行，否则返回“当前位置清零指令无效”。
- 磁极检测锁轴电压过低可能导致锁轴刚度不足，过高可能导致过流。

### 反馈页写入映射

| 功能 | 写入参数/命令 |
|---|---|
| Nikon/Tamagawa/Biss-C 编码器类型 | `Pn004=1`，`Pn006=单圈位数`，`Pn009=厂商/协议组`；Biss-C 还会写 `Pn150=多圈位数` |
| 增量式编码器 | `Pn004`：非省线为 0，省线为 3 |
| 编码器绝对位置清零 | `Pn101` 依次写 `0 → 1 → 0`，且要求驱动器下使能 |
| 磁极检测使能 | `Pn050` |
| 磁极检测旋转时间 | `Pn103` |
| 磁极检测频率 | `Pn110` |
| 磁极检测锁轴电压 | `Pn109` |
| 磁极检测启动 | `55 55 7A A7 A7 7A AA AA` |
| 等价编码器输出类型 | `Pn124` |
| 等价编码器每圈脉冲高四位 | `Pn123` |
| 等价编码器每圈脉冲低四位 | `Pn122` |

编码器下拉框共 21 项：Nikon 3 项、Tamagawa 2 项、Biss-C 10 项、
增量式编码器 6 项。

## 7. 制动器

- 控制类型：伺服 ON/OFF 控制、强制松开、强制闭合。
- 参数：制动器控制电压和稳态保持电压。
- 可选 PWM OFF 延迟时间。
- 垂直安装负载在伺服 OFF 后可能下滑，延迟时间用于保持制动器足够长时间。
- 强制松开/闭合属于高风险动作，不能在未确认机械安全时自动执行。

## 8. 限定与保护

页面包含：

- 母线电压限定和报警阈值。
- 电流限定。
- 电机长时过载保护倍数。
- 驱动器瞬时过载保护倍数。
- 电机额定电流。
- 转速限定和转速报警阈值。

参考版把保护参数与故障处理关联，例如：

- Er005 检查 `Pn085` 和 `Pn092`。
- Er006 检查 `Pn085` 和 `Pn091`。
- Er014/Er015 检查 `Pn130`、脉冲输入类型和每转指令脉冲数。

## 9. 再生电阻

- 核心字段为“再生电阻投入电压阈值”。
- 参考错误表提示 Er020 时需要检查再生电阻是否接入、功率等级、
  驱动器型号设置和 `Pn020` 阈值。

## 10. 数字 I/O

### 数字输入

- 伺服 ON（内部速度模式）
- 回零命令
- 机械原点
- 正转驱动禁止
- 反转驱动禁止
- 报警复位
- 伺服 ON（位置齿轮模式）

### 数字输出

- 回零完成
- 伺服报警
- 伺服准备就绪
- 编码器模拟 Z 脉冲
- 制动器（刹车）控制
- 保留输出

表格字段包括名称、功能、有效电平和连接端子。参考事件使用
`Pn013/Pn014` 处理输入配置，使用 `Pn015/Pn016` 处理输出配置。

## 11. 使能与故障

- 页面分为当前警告、当前伺服报警和报警历史记录。
- `ErrorCode.XML` 共提供 45 条错误/警告/运动限制记录。
- 每条记录包含代码、说明和处理办法。
- 常见分组：
  - `Er0xx`：硬件过载、过压、编码器、软件过载和转速异常。
  - `Er1xx/2xx`：绝对值编码器通信、电池、位置和温度问题。
  - `Er3xx/4xx`：EtherCAT 通信、周期和丢帧问题。
  - `Ar0xx`：正/负限位、软限位、节点地址和总线波特率问题。
- 报警复位、驱动使能和驱动停止是独立高风险命令。

## 12. 电流环

- 电流环比例增益 `KCP`。
- 电流环积分增益 `KCI`。
- 反电势补偿系数 `KEMF`。
- 反电势补偿开关。

确认映射：`Pn031=KCP`、`Pn032=KCI`、`Pn141=KEMF`，`Pn140` 的
0/1 分别为 Disabled/Enabled。

## 13. 速度环

- 速度环比例增益 `KVP`。
- 速度环积分增益 `KVI`。
- 速度前馈 `KVFR`。
- 速度反馈滤波时间。
- 速度环输出滤波的频率、宽度、深度和截止频率。

确认映射：`Pn033=KVP`、`Pn034=KVI`、`Pn035=KVFR`。

## 14. 位置环

- 位置环比例增益 1 `KPP1`。
- 位置环积分增益 `KPI`。
- 位置环比例增益 2 `KPP2`。
- 位置前馈 `KPVFR`。
- 平滑位置指令滤波 `PCMDF`。
- 位置环输出滤波 `POUTF`。

确认映射：

| 参数 | 含义 |
|---|---|
| `Pn065` | 位置环比例增益 1 KPP1 |
| `Pn068` | 位置环积分增益 KPI |
| `Pn063` | 位置环比例增益 2 KPP2 |
| `Pn064` | 位置前馈 KPVFR |
| `Pn066` | 平滑位置指令滤波 PCMDF |
| `Pn067` | 位置环输出滤波 POUTF |

## 15. 控制与位置齿轮

- 可调电流环、速度环和位置环增益。
- 目标位置、目标速度和目标加减速度。
- 运动模式包括绝对、相对、单次和往返。
- 往返模式包含停止时间。
- 位置齿轮包含每转指令脉冲数、脉冲输入类型和从站节点地址。
- 修改脉冲输入类型通常需要重新上电。

## 16. 驱动模式

驱动模式包括：

- 串行电流
- 串行速度
- 串行位置
- 位置齿轮
- 回零
- 内部速度

页面还提供：

- 扭矩指令千分比（占电机额定扭矩）。
- 目标速度、目标位置和加减速时间。
- 运行/停止控制。
- 编码器位置清零。
- 脉冲输入类型。
- EtherCAT/Canopen 从站节点地址。

切换驱动模式要求驱动器处于下使能状态。

### 驱动模式写入映射

| 参数 | 含义 |
|---|---|
| `Pn001` | 驱动模式：串行电流、串行速度、串行位置、位置齿轮、回零、内部速度 |
| `Pn031` | 电流环 KCP |
| `Pn032` | 电流环 KCI |
| `Pn033` | 速度环 KVP |
| `Pn034` | 速度环 KVI |
| `Pn065` | 位置环 KPP1 |
| `Pn063` | 位置环 KPP2 |
| `Pn064` | 位置前馈 KPVFR |
| `Pn066` | 平滑位置指令 PCMDF |
| `Pn067` | 位置环输出滤波 POUTF |
| `Pn008` | 脉冲输入类型 |
| `Pn058/Pn059` | 每转指令脉冲数高低四位 |
| `Pn120` | 从站节点地址 |

## 17. 回零

参考版支持以下 `Homing method (0x6098)`：

| 方法 | 语义 |
|---|---|
| 1 | 离开负限位后，第一个 Index 标记回零 |
| 2 | 离开正限位后，第一个 Index 标记回零 |
| 7 | 离开原点开关负边沿，寻找第一个 Index，初始正向 |
| 8 | 接触原点开关负边沿，寻找第一个 Index，初始正向 |
| 9 | 接触原点开关正边沿，寻找第一个 Index，初始正向 |
| 10 | 离开原点开关正边沿，寻找第一个 Index，初始正向 |
| 11 | 离开原点开关正边沿，寻找第一个 Index，初始负向 |
| 12 | 接触原点开关正边沿，寻找第一个 Index，初始负向 |
| 13 | 接触原点开关负边沿，寻找第一个 Index，初始负向 |
| 14 | 离开原点开关负边沿，寻找第一个 Index，初始负向 |
| 24 | 接触原点开关负边上升沿回零，初始正向 |
| 28 | 接触原点开关正边上升沿回零，初始负向 |
| 33 | 第一个 Index 标记回零，初始负向 |
| 34 | 第一个 Index 标记回零，初始正向 |
| 35 | 声明当前位置为零位 |

回零页还包含：

- 回零偏置。
- 第一回零速度（寻找开关）。
- 第二回零速度（寻找零位）。
- 回零加减速时间。

示意图明确展示挡片初始位置、Index、HOME、NOT/POT 开关、两段速度方向和
最终回零位置。Qt 版已把这些示意图和方法说明引入资源并按方法编号切换。

## 18. 运动页

- 设定目标位置、目标速度和加减速时间。
- 支持绝对/相对、单次/往返。
- 往返模式可设置停止时间。
- 开始和停止命令必须与使能状态、软限位和机械行程共同检查。

## 19. 示波图

- 参考系列包括速度指令 `VCMD`、速度 `V`、位置指令 `PCMD`、位置 `P`、
  位置误差 `PE`、电流指令 `ICMD`、电流 `I` 和参数 `Para`。
- 每个通道可单独显示/隐藏并设置单位。
- 页面提供 X 轴时间范围、Y 轴范围、暂停、清空和运行控制。
- 当前 Qt 版已实现 7 个反馈通道叠加，但尚无独立指令通道和通道增益/偏移设置。

## 20. 备份与恢复

- 参考版使用“读参数”和“写参数”图标表达设备到文件和文件到设备的流程。
- 参数文件格式为 `.txt`。
- 当前 Qt 版使用参数 CSV，支持导入、导出和写入设备前确认。

## 21. Tuning、Configuration、General

- 参考主菜单中存在这些入口，其中一部分复用性能参数和驱动模式控件。
- 目前可确认的核心语义已由控制环、驱动模式和连接配置覆盖。
- 未提取到独立字段的隐藏/定制控件不会凭空生成自动写入接口。

## 22. 当前 Qt 实现状态

已具备：

- 常驻实时状态带和驱动运行时状态。
- 可滚动完整功能导航。
- 参数紧凑网格与详细表格。
- 多通道示波。
- 电机、制动器、限定与再生电阻专用配置页。
- 回零方式示意图浏览。
- 45 条故障代码检索和故障复位入口。
- 数字 I/O 功能、极性和端子映射骨架。

后续需要：

- 建立完整编码器类型/反馈页。
- 接入控制环字段与参考参数编号的精确映射。
- 实现运动、驱动模式和回零参数的受控写入与实机联锁。
- 增加指令/反馈双通道示波和通道增益、偏移、单位设置。
