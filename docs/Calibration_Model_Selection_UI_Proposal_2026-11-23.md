# 标定型号选择与自定义分段 UI 改造方案

> 分析日期：2026-11-23
> 当前分支：`AHR_origin`
> 当前 UI 基线：`mainwindow.ui`、`mainwindow.cpp`
> 阶段：只做设计与方案，不修改代码

> 2026-11-24 更新：已按后续 UI 决策将型号、范围、分段和误差比例移入
> 独立“标定设置”对话框；主窗口增加“设置”菜单，步骤一仅保留当前方案摘要和打开设置按钮。

## 1. 本次目标

在当前 EHA/ECM 五步标定工具上增加“设备型号 + 标定范围 + 算法 + 合格判定”配置：

| 设备型号 | 额定满量程 | 默认标定范围 | 标定方式 | 默认误差上限 |
|---|---:|---:|---|---:|
| `ECM1A2000` | 0–2000 N | 0–2000 N | 特殊查表法 | ±30 N |
| `ECM1A200` | 0–200 N | 0–200 N | K/B 拟合 | ±3 N |
| `ECM1A500` | 0–500 N | 0–500 N | K/B 拟合 | ±7.5 N |

“自定义”不是独立的硬件型号，而是对 `ECM1A200` 或 `ECM1A500` 选择窄标定范围及分段。

例如：

```text
设备型号：ECM1A500
额定满量程：0–500 N
标定范围：0–100 N
分段：10 N
误差比例：1.5%
允许误差：±（500 × 1.5%）= ±7.5 N
```

也就是说，实际标定只覆盖 0–100 N，但产品合格判定仍以 500 N 硬件满量程的 1.5% 为基准。

自定义示例：

```text
X = 100 N
分段 = 10 N
测试输入力 = 0, 10, 20, ..., 100 N
```

本方案以不改动设备协议和串口写入格式为前提，重新组织 UI、数据模型、测试点生成和标定结果。

## 2. 当前 UI 设计风格

### 2.1 总体视觉

当前界面是典型的工业设备向导式布局：

```text
┌─────────┬──────────────┬────────────────────────┐
│ 深色步骤栏 │ 左侧操作步骤   │ 中央设备姿态示意图       │
│ 161 px   │ 约 281 px     │ 约 811 px              │
├─────────┴──────────────┴────────────────────────┤
│ 底部运行日志，覆盖左侧步骤区和图片区下方              │
└────────────────────────────────────────────────┘
```

核心视觉特征：

- 黑白灰主色；
- 深灰步骤栏 `#3D3C3D`；
- 浅灰页面渐变 `#F0F0F0 → #D0D0D0`；
- 按钮统一深灰 `#616161`；
- 白色输入框、圆角 8 px；
- 大圆角按钮 12 px；
- 中央使用橙黄色 KUKA 机器人和 EHA 设备姿态示意图；
- 字体混用 Microsoft YaHei 和 Cascadia Mono；
- 使用绿色确认图标表示已完成的步骤。

整体风格是“工业设备操作台/步骤向导”，不是现代后台管理系统，也不是紧凑数据仪表盘。

### 2.2 当前主要区域

| 区域 | 尺寸/位置 | 设计方式 |
|---|---|---|
| 主窗口 | 固定 1280×720 | 绝对定位，不支持响应式缩放 |
| 左侧步骤栏 | x=0，宽 161，高 721 | 深色 `QGroupBox` + 5 个 `QToolButton` |
| 五步操作区 | x=160，宽 281，高 565 | 隐藏标签栏的 `QTabWidget` |
| 中央姿态图 | x=450，宽 811，高 511 | `QLabel` + `QPixmap`，按 KeepAspectRatio 缩放 |
| 底部日志 | x=160，宽 1121，高 181 | 浅灰只读 `QTextEdit` |

这套布局比较依赖固定坐标。增加型号字段后，不应对主窗口做大幅重排，而应在左侧 281 px 操作区
内部重新分配垂直空间。

### 2.3 页面与导航

- `QTabWidget` 的 `tab-bar` 高度被设置为 0，因此页签不可见；
- 页面切换由前后箭头完成；
- 左右箭头是图标 `QToolButton`；
- 侧边 `STEP1–STEP5` 只作为进度指示，没有连接点击槽；
- 页面切换后，前面所有步骤会自动变成完成状态；
- 当前 `mainwindow.ui` 的 `currentIndex` 预设为 3，构造函数启动时再淡出切换到 0；
- 因此程序启动初期可能出现短暂页面闪烁。

### 2.4 控件设计方式

#### `QTabWidget`

- 隐藏标签栏；
- pane 使用垂直灰色渐变；
- 圆角 16 px；
- 实际承担“向导页面容器”而不是普通标签页。

#### `QPushButton`

- 所有业务按钮使用同一套深灰样式；
- 白色 14 px 文本；
- 10×24 px 内边距；
- 12 px 圆角；
- hover 变为 `#757575`；
- pressed 变为 `#424242`；
- disabled 变为 `#9E9E9E`。

问题：

- 普通操作、高风险操作、确认操作没有颜色区分；
- 每个按钮都复制了一遍相同的 QSS，维护成本高；
- “连接”“EHA检测”“EHA初始化”“EHA标定”“力矩清零”视觉权重相同，不利于操作安全。

#### `QToolButton`

三种用途：

1. 串口刷新：深灰圆角 14 px；
2. 前后步骤箭头：透明背景、无边框、25 px 图标；
3. 左侧步骤指示：深色背景、32 px 确认图标、文字+图标水平排列。

#### `QComboBox`

- 串口选择使用；
- 8 px 圆角；
- 白色/浅灰背景；
- 自定义下拉箭头；
- 自定义下拉列表滚动条。

问题：

- QSS 引用了 `:/image/combox.png`，但当前 `image.qrc` 没有该资源；
- 下拉框的实际箭头可能缺失或回退；
- QSS 的滑动条伪状态选择器顺序存在错误。

#### `QLineEdit`

- IP 地址和当前质量补偿输入使用；
- 白色背景、1 px 灰边框、8 px 圆角、5 px 内边距；
- IP 地址居中显示。

问题：

- 质量补偿使用普通文本输入，没有数值控件和范围限制；
- 新增力范围/分段不应继续使用 `QLineEdit`，应改用 `QSpinBox`。

#### `QLabel`

- 用于步骤说明、实时力和中央姿态图片；
- 实时力标签带边框和圆角；
- 中央图片按窗口尺寸缩放。

问题：

- 实时力在无数据时仍显示文字“实时力”，没有明确的 `-- N` 空状态；
- 型号、标定算法、分段信息没有状态展示位置。

#### `QTextEdit`

- 只读运行日志；
- 浅灰背景、深灰文字；
- 12 pt Microsoft YaHei；
- 自定义细滚动条。

它是操作员了解流程进度的主要信息来源。后续应在日志之外增加结构化的“当前配置/结果”区域，
不要让关键 K/B 值只能从日志中查找。

#### `QGroupBox`

- 左侧深色步骤栏；
- 4 px 深灰边框；
- 8 px 圆角；
- QSS 中写了 `box-shadow`，但 Qt Widgets QSS 不支持该属性。

### 2.5 当前 UI 的问题

1. 步骤完成状态只由页面索引决定，不代表实际业务成功；
2. 前后箭头没有业务门槛；
3. 所有按钮同色，危险与普通动作无法区分；
4. 控件 QSS 大量重复；
5. 固定 1280×720，不适合小屏和高 DPI；
6. 左侧步骤栏中的步骤按钮没有交互；
7. 关键实时力没有单位、有效性和更新时间；
8. 无“当前型号、算法、范围、分段、采样点数”摘要；
9. 无 K/B 计算结果显示区；
10. 页面没有运行中锁定、停止和取消。

## 3. 对两种标定算法的理解

### 3.1 ECM1A2000：查表标定

范围：

```text
0–2000 N
```

方式：

- 在若干设定力点采集力传感器实际力；
- 把实际力写入驱动器内部标定查找表；
- 当前项目已知查找表区域为：
  - `Pn140–Pn149`；
  - `Pn180–Pn189`。

推荐采点：

```text
0, 200, 400, 600, 800, 1000, 1200, 1400, 1600, 1800, 2000
```

其中：

- 0 N 用于零点检测和报告基准；
- 200–2000 N 共 10 个非零点，对应 PN140–PN149 和 PN180–PN189；
- 正向按 200→2000 逐点写入；
- 反向按 2000→200 采集，但结果按 200→2000 的固定索引写入。

已确认规则：

- `Pn140` 对应 200 N，后续依次到 `Pn149=2000 N`；
- `Pn180` 对应 200 N，后续依次到 `Pn189=2000 N`；
- 0 N 默认视为 0，不写入 Pn140–Pn149 或 Pn180–Pn189。

### 3.2 ECM1A200 / ECM1A500：K/B 拟合

范围：

- ECM1A200：0–200 N；
- ECM1A500：0–500 N。

推荐默认分段：

- ECM1A200：20 N；
- ECM1A500：50 N。

对应采样点：

```text
ECM1A200: 0, 20, 40, ..., 200
ECM1A500: 0, 50, 100, ..., 500
```

每个设定点执行正向和反向测试，形成：

```text
设定力 x_i
正向实际力 yF_i
反向实际力 yR_i
```

拟合和合格判定只使用正向数据。反向数据仅记录和报告，不参与 K/B 计算，也不决定测试是否通过。

如果同一设定点采集了多次正向样本，先求该点的正向平均值：

```text
y_i = average(forward samples at x_i)
```

再用最小二乘拟合：

```text
y = K × x + B
```

其中：

- `K` 为斜率；
- `B` 为截距；
- 反向数据单独保存为参考值；
- 不使用正反向平均生成 K/B。

最终写入规则已确认：

```text
实际力 = 输入力 × K + B
K 计算值 × 10 = Pn168 原始整数
```

例如：

```text
拟合 K = 250.6
Pn168 = round(250.6 × 10) = 2506
```

Pn169 的工程 B 与原始整数的换算关系尚未确认。因此：

- 程序计算并显示拟合 B；
- 程序显示 Pn169 当前值和可编辑的原始录入值；
- Pn169 不自动按某个未知比例换算；
- 操作者可以在写入前手动修改 Pn169；
- 确认框同时显示拟合 B、Pn169 原始值和最终写入帧预览。

例如：

```text
拟合 B = 500
Pn169 原始录入值 = 50
```

程序应提示这两个数含义不同，不能把 500 自动当成原始 Pn169。

拟合公式：

```text
K = (nΣxy - ΣxΣy) / (nΣx² - (Σx)²)
B = (Σy - KΣx) / n
```

还应计算：

- `R²`；
- 最大绝对误差；
- 最大正反向迟滞；
- RMS 误差。

在写入设备之前，必须弹出预览：

```text
标定方式：线性拟合
K（计算） = ...
Pn168（K×10） = ...
B（计算） = ...
Pn169（人工确认原始值） = ...
R² = ...
最大误差 = ...
允许误差 = ...

确认写入 Pn168 / Pn169？
```

### 3.3 误差判定

实际力的线性拟合方向已经确认：

```text
实际力 = 输入力 × K + B
```

误差判定默认公式：

```text
允许误差 N = 所选型号额定满量程 × 误差比例
合格条件 = -允许误差 N ≤ (正向实际力 - 设定力) ≤ +允许误差 N
```

默认误差比例：

```text
1.5%
```

对应结果：

| 型号满量程 | 默认允许误差 |
|---:|---:|
| 2000 N | ±30 N |
| 500 N | ±7.5 N |
| 200 N | ±3 N |

界面应允许修改误差比例，并显示实时换算后的 N 值。修改对象建议是比例，而不是直接改 N：

```text
误差比例：1.5 %
判定基准：500 N
允许误差范围：±7.5 N
```

这样即使 `ECM1A500` 只标定 0–100 N，允许误差仍然是 7.5 N，而不是 1.5 N。

例如：

```text
设定力 = 100 N
允许范围 = 100 ± 7.5 N
合格区间 = 92.5–107.5 N
```

反向数据只显示在结果和报告中，不参与这里的高低限判断。

## 4. 窄范围标定与自定义分段

### 4.1 输入控件

在 `ECM1A200` 或 `ECM1A500` 下选择“自定义标定范围”时需要：

| 字段 | 控件 | 建议范围 |
|---|---|---|
| 力上限 X | `QSpinBox` | 1–所选型号额定满量程 |
| 分段步长 Δ | `QSpinBox` | 1–X N |
| 预览 | `QLabel` | 自动生成测试点 |

硬限制：

- 任何型号均不允许使用超过 2000 N 的标定上限；
- `ECM1A200` 的自定义上限不得超过 200 N；
- `ECM1A500` 的自定义上限不得超过 500 N；
- `ECM1A2000` 使用固定 0–2000 N 查表流程，不进入 K/B 自定义范围。

不建议使用 `QLineEdit`，原因：

- 无法阻止负数；
- 无法阻止空值；
- 无法自动限制范围；
- 后续每增加一个输入都要重复写校验。

### 4.2 测试序列生成规则

推荐先生成：

```text
0, Δ, 2Δ, ..., floor(X / Δ) × Δ
```

如果最后一个值不等于 X，有两种方案：

#### 已确认方案：自动追加终点

```text
X = 105, Δ = 10
生成：0, 10, 20, ..., 100, 105
```

优点：

- 一定测试到量程上限；
- 更符合安全验收。

缺点：

- 最后一段不是固定长度。

#### 严格方案：要求 X 能被 Δ 整除

```text
105 / 10 不是整数
禁止开始，并提示调整 X 或 Δ
```

已确认采用“自动追加终点”，并在配置摘要中清晰显示完整点表。

### 4.3 自定义模式算法

自定义范围固定使用 **K/B 线性拟合**。

- `ECM1A200 + 0–100 N`：K/B；
- `ECM1A500 + 0–100 N`：K/B；
- 不提供“自定义范围 + 查表”组合；
- 只有 `ECM1A2000` 使用查表方式。
- 自定义范围同时作为检测、标定和最终验证范围，不另设第二套验证范围。

这正好覆盖“500 N 额定模块实际只需要标定 0–100 N 或 0–200 N”的应用场景。设备额定满量程决定：

- 误差判定基准；
- 允许的标定上限；
- 报告中的产品等级；
- 不能只根据实际标定上限反推产品能力。

## 5. 推荐型号配置

### 5.1 配置表

| 型号 | 额定满量程 | 默认标定上限 | 默认分段 | 算法 | 误差基准 |
|---|---:|---:|---:|---|---:|
| `ECM1A2000` | 2000 N | 2000 N | 200 N | 查表 | 2000 N |
| `ECM1A200` | 200 N | 200 N | 20 N | K/B | 200 N |
| `ECM1A500` | 500 N | 500 N | 50 N | K/B | 500 N |

`ECM1A200` 和 `ECM1A500` 可以把“标定上限”改为小于额定满量程的自定义值。

示例：

| 型号 | 额定满量程 | 标定上限 | 分段 | 误差比例 | 允许误差 |
|---|---:|---:|---:|---:|---:|
| ECM1A500 全量程 | 500 N | 500 N | 50 N | 1.5% | 7.5 N |
| ECM1A500 窄范围 | 500 N | 100 N | 10 N | 1.5% | 7.5 N |
| ECM1A200 窄范围 | 200 N | 100 N | 10 N | 1.5% | 3 N |

### 5.2 配置结构

代码阶段建议增加：

```cpp
enum class CalibrationAlgorithm {
    LookupTable,
    LinearFit
};

struct CalibrationProfile {
    QString id;
    QString displayName;
    int minForceN;
    int ratedMaxForceN;
    int calibrationMaxForceN;
    int stepN;
    CalibrationAlgorithm algorithm;
    double tolerancePercent;
    bool narrowRange;
};
```

其中：

- `ratedMaxForceN` 决定误差基准和产品等级；
- `calibrationMaxForceN` 决定实际测试上限；
- `stepN` 决定采点间隔；
- `tolerancePercent` 默认 1.5；
- 允许误差由 `ratedMaxForceN × tolerancePercent` 计算。

测试点不要分散写在检测、标定和报告三个函数中，而应由统一函数生成：

```cpp
QVector<int> buildForcePoints(const CalibrationProfile &profile);
```

这样才能保证：

- 检测点一致；
- 标定点一致；
- 验收点一致；
- 报告点一致；
- 图表横轴一致。

## 6. UI 改造方案

### 6.1 放置位置

建议将“标定配置”放在步骤一的左侧操作面板，位于串口/IP 连接信息之前或之后。

推荐顺序：

```text
步骤一
├─ 标定配置
│  ├─ 设备型号
│  ├─ 标定范围模式（全量程/自定义）
│  ├─ 自定义上限（仅窄范围显示）
│  ├─ 自定义分段（仅窄范围显示）
│  ├─ 误差比例
│  ├─ 换算后的允许误差
│  ├─ 算法摘要
│  └─ 点表预览
├─ 连接设置
│  ├─ ECM 串口
│  ├─ 力传感器 IP
│  └─ 连接按钮
└─ 下一步
```

把型号放在连接前，可以让程序在建立设备会话时就固定标定策略，避免连接后更改型号导致数据混用。

### 6.2 型号控件

使用：

```text
QComboBox modelComboBox
```

选项：

```text
ECM1A2000（0–2000 N，查表）
ECM1A200（0–200 N，K/B）
ECM1A500（0–500 N，K/B）
```

建议用数据角色保存稳定型号 ID，不使用显示文本作为业务判断。

型号不再直接提供“自定义”项。选择 `ECM1A200` 或 `ECM1A500` 后，再选择：

```text
标定范围：全量程 / 自定义
```

选择“自定义”时，开放标定上限和分段。这样 `500 N` 型号仍然保留“额定满量程=500 N”的
产品信息，不会被误认为一台 100 N 型号。

### 6.3 自定义区域

自定义范围使用一个独立容器：

```text
QWidget narrowRangeConfig
├─ QLabel "标定上限 X"
├─ QSpinBox maxForceSpin
├─ QLabel "分段 Δ"
├─ QSpinBox stepForceSpin
└─ QLabel pointPreviewLabel
```

只有选择“自定义标定范围”时显示。

推荐默认：

- `X = 100 N`；
- `Δ = 10 N`；
- 后缀统一为 ` N`；
- 不允许 X 或 Δ 为 0；
- 不允许 Δ > X。
- 不允许 X 超过所选型号额定满量程。
- `ECM1A2000` 不显示该区域。

### 6.4 配置摘要

在型号下方增加只读摘要：

```text
型号：ECM1A500
额定满量程：0–500 N
实际标定范围：0–100 N
分段：10 N
算法：K/B 拟合
误差比例：1.5%
允许最大误差：7.5 N
采样：0, 10, 20, ..., 100（11 点）
```

误差比例使用 `QDoubleSpinBox`，建议范围 `0.1–10.0 %`，默认 `1.5 %`。

旁边实时显示：

```text
允许误差 = 500 × 1.5% = 7.5 N
```

操作者修改比例后立即重算 N 值。

原摘要示例可保留为：

```text
范围：0–100 N
分段：10 N
算法：K/B 拟合
采样：0, 10, 20, ..., 100（11 点）
```

如果点表较长，可只显示前几个、最后几个和总数：

```text
0 / 10 / 20 / … / 100 N，共 11 点
```

### 6.5 避免布局跳动

自定义字段使用固定高度的容器，切换到固定型号时：

- 方案 1：隐藏并保留空间；
- 方案 2：禁用并显示固定型号值。

推荐方案 2：

```text
标定上限 X：500 N（只读）
分段 Δ：50 N（只读）
```

这样用户始终能看到实际标定范围，布局也不会突然变化。

## 7. 各页面随型号变化

### 7.1 步骤一：连接与型号

新增：

- 型号选择；
- 全量程/自定义范围选择；
- 自定义范围和分段；
- 误差比例与允许误差；
- 当前算法摘要；
- 采样点预览。

连接成功后锁定型号，除非用户主动断开并确认清空本次数据。

### 7.2 步骤二：检测与初始化

测试按钮使用的力序列必须来自 `buildForcePoints()`。

显示：

```text
当前型号：ECM1A500
实际标定范围：0–100 N
额定满量程：0–500 N
分段：10 N
允许误差：7.5 N
预计正反向采样：11 × 2
```

检测结果表或日志至少记录：

- 设定力；
- 正向实际力；
- 反向实际力；
- 平均力；
- 偏差；
- 数据是否有效。

### 7.3 步骤三：标定

根据算法显示不同按钮和结果：

#### ECM1A2000

按钮：

```text
开始查表标定
```

结果：

```text
将写入 Pn140–Pn149
将写入 Pn180–Pn189
不修改 Pn168/Pn169
```

Pn140 对应 200 N，Pn149 对应 2000 N；Pn180/Pn189 同理。0 N 不写查表参数。

#### K/B 模型

按钮：

```text
采集并计算 K/B
```

计算完成后不要立即写入，先显示：

```text
K（计算） =
Pn168 = round(K × 10) =
B（计算） =
Pn169（可人工修改） =
R² 基于正向点 =
正向最大误差 =
反向最大误差（仅参考） =
允许误差 =
```

K/B 拟合只使用每个设定力的正向采样。反向采样可以展示在日志和报告中，但：

- 不参与 K/B 计算；
- 不参与最终合格判断；
- 不改变写入的 Pn168/Pn169。

需要分别设计三个控件：

1. `QDoubleSpinBox fittedKDisplay`：只读，显示计算 K；
2. `QSpinBox pn168Spin`：显示/允许微调 `round(K × 10)`；
3. `QSpinBox pn169Spin`：只读计算 B 不足以确定原始值，因此允许操作者手动录入。

推荐 Pn169 区域显示：

```text
拟合 B：500.0
设备当前 Pn169：0
Pn169 写入值：[ 50 ]
```

程序不应偷偷执行：

```text
Pn169 = round(B)
```

因为当前没有可信的 B 原始值换算规则。操作者必须能看到拟合 B，并独立确认原始 Pn169。

Pn169 当前阶段只暴露原始整数输入：

```text
范围：0–65535
默认：设备当前 Pn169 或 0
负数逻辑编码：暂不自动解释
```

再通过确认框写入 Pn168/Pn169。确认框应同时显示：

```text
Pn168 = 2506
Pn169 = 50
```

如果用户取消，采集数据保留，便于重新计算。

### 7.4 步骤四：力矩清零

与型号无关。

同时修复当前按钮永久禁用问题。

### 7.5 步骤五：质量补偿和验收

最终 EHA 检测使用当前型号的同一套点表，而不是固定 0–2000。

如果自定义为 0–100、步长 10，则最终验收应为：

```text
0, 10, 20, ..., 100 N
```

不要重新写死检测点。

合格判定仍然为：

```text
ECM1A500 的允许误差 = ±（500 × 1.5%）= ±7.5 N
```

不能因为标定范围只有 100 N，就把允许误差缩小为 1.5 N。

## 8. 数据模型改造

### 8.1 当前数据容器

当前使用：

```cpp
QVector<quint16> m_testForwardValues;
QVector<quint16> m_testReverseValues;
QVector<quint16> m_calibForwardValues;
QVector<quint16> m_calibReverseValues;
```

问题：

- 只知道值，不知道对应设定力；
- 不知道数据时间；
- 不知道是否有效；
- 预填 0 后无法区分“真实 0”和“没有读到”；
- 无法支持不同型号的点表。

### 8.2 建议数据模型

```cpp
struct ForceSample {
    int setForceN = 0;
    double rawSensor = 0.0;
    double actualForceN = 0.0;
    QDateTime timestamp;
    bool valid = false;
};

struct CalibrationRun {
    CalibrationProfile profile;
    QVector<ForceSample> forward;
    QVector<ForceSample> reverse;
    double k = 0.0;
    double b = 0.0;
    int pn168Target = 0;
    int pn169Target = 0;
    bool pn169ManuallyConfirmed = false;
    double toleranceN = 0.0;
    double rSquared = 0.0;
    double maxError = 0.0;
    double maxHysteresis = 0.0;
    bool fitValid = false;
};
```

这样可以自然区分：

- 真正的 0 N 采样；
- 尚未读取的采样；
- 读取失败的采样；
- 每个样本属于哪个型号和哪个过程。

## 9. 标定执行流程建议

### 9.1 统一流程

```text
选择型号
    ↓
生成点表
    ↓
连接 EHA + 力传感器
    ↓
初始化
    ↓
正向采样
    ↓
反向采样
    ↓
数据完整性检查
    ↓
按算法计算
    ├─ 查表结果
    └─ K/B 拟合结果
    ↓
用户预览确认
    ↓
写入 PN
    ↓
Pn152=1 保存
    ↓
回读检查
    ↓
最终验收
    ↓
导出报告
```

### 9.2 状态锁定

运行过程中应禁用：

- 型号选择；
- 自定义范围；
- 自定义分段；
- 连接/断开；
- 初始化；
- 检测；
- 标定；
- 清零；
- 质量补偿；
- 报告导出。

只保留“停止/取消”可用。

### 9.3 数据完整性

K/B 写入前必须满足：

- 所有设定点都有有效的正向样本；
- 0 点数据有效；
- 传感器样本时间在对应 Pn044 命令之后；
- 斜率有限且不为 0；
- `Pn168 = round(K×10)` 在 0–65535 内；
- Pn169 原始值由操作者确认且在 0–65535 内；
- 正向最大绝对误差与允许误差已计算；
- 用户已经看过拟合结果。

反向数据：

- 可用于报告和现场观察；
- 缺测或超差不作为 K/B 写入的阻断条件；
- 但应在日志中标记“反向参考数据缺失”或“反向参考超标”。

## 12. 已确认业务规则

### 12.1 已确认

#### K/B 关系

```text
实际力 = 输入力 × K + B
```

#### Pn168 写入

```text
Pn168 = round(K × 10)
```

例如：

```text
K = 250.6
Pn168 = 2506
```

#### Pn169 写入

- 拟合 B 与 Pn169 的原始值比例暂时未知；
- Pn169 必须是整数；
- 必须允许操作者手动修改 Pn169 的原始录入值；
- 不自动假设 `Pn169 = round(B)`；
- 后续若确认了比例，可在手工值旁边增加“建议换算值”，但仍以操作者确认值为准。

#### ECM1A2000

- 固定 0–2000 N；
- 测试点包含 `0, 200, …, 2000`；
- Pn140–Pn149 对应 200–2000 N；
- Pn180–Pn189 对应 200–2000 N；
- 0 N 不录入查表参数；
- 查表模式不写入 K/B。

#### 窄范围

- `ECM1A200` 和 `ECM1A500` 可选择小于额定满量程的标定上限；
- 标定上限不能超过型号额定满量程；
- 所有型号均不能超过 2000 N；
- 自定义范围固定使用 K/B；
- 例如 `ECM1A500 + 0–100 N` 仍属于 500 N 型号。

#### 误差判定

- 默认误差比例 1.5%；
- 误差为双向容差，即 ±1.5%；
- 误差基准是型号额定满量程，而不是实际标定范围；
- ECM1A2000：±30 N；
- ECM1A500：±7.5 N；
- ECM1A200：±3 N；
- 只检查正向实际力与设定力的差；
- 反向测试仅作为参考数据；
- 界面允许操作者修改误差比例。

#### 自定义范围

- 自定义是标定范围模式；
- 标定、检测和最终验证使用同一个范围；
- 不能被 Δ 整除时自动追加终点；
- 固定使用 K/B 拟合。

#### 正向数据

- K/B 拟合只使用正向数据；
- 每个点若有多次采样，取正向平均值；
- 合格判定只使用正向实际力与设定力的绝对误差；
- 反向测试的原始数据记录在日志和报告中，仅作参考。

#### Pn169 输入

- 直接暴露 0–65535 的原始整数输入；
- 首版不解释负值逻辑；
- 设备当前 Pn169 可作为默认候选值；
- 写入前必须由操作者确认。

### 12.2 推荐实现默认

以下不再作为阻断问题，按推荐默认实现：

1. 写入 Pn168/Pn169 后自动回读一次并提示核对；
2. 误差比例作为最终验收和报告字段，不在 K/B 拟合阶段阻断写入；
3. 报告中同时记录额定满量程和实际标定范围；
4. 运行中锁定型号、范围和分段；
5. 切换型号或范围时，若已有未导出数据，提示清空；
6. 反向数据采集失败不阻止 K/B 写入，但日志显示警告。

## 15. 本阶段结论

本次改造不应只是增加一个型号下拉框，而应把“型号额定满量程 → 实际标定范围 → 点表 →
测试方法 → 标定算法 → 参数写入 → 误差判定 → 报告字段”做成一条统一的数据链。

推荐先按以下默认方案实施：

- ECM1A2000：额定/标定均为 0–2000 N、200 N 分段、查表、允许误差 ±30 N；
- ECM1A200：额定 0–200 N，可全量程或窄范围、默认 20 N 分段、K/B、允许误差 ±3 N；
- ECM1A500：额定 0–500 N，可全量程或窄范围、默认 50 N 分段、K/B、允许误差 ±7.5 N；
- 窄范围：不超过型号额定满量程，固定 K/B，自动包含终点；
- Pn168：`round(K×10)`；
- Pn169：操作者手工确认 0–65535 原始整数；
- K/B 和合格判断只使用正向数据；
- 反向数据只作为参考记录。

当前业务规则已足够进入代码修改阶段。
