# KaiserStudio Qt

这是一个面向转数/位置伺服驱动器的 Qt 串口调试工作台，界面与工作流参考
`KaiserStudio`，并基于本项目已有的 EHA 串口协议重新组织代码。

当前阶段的 Git 状态、已完成功能、验证记录和后续待办，请先阅读
[阶段工作汇总](docs/KaiserStudio_Stage_Summary_2026-10-29.md)。

## 当前功能

- 串口自动枚举，支持波特率、数据位、校验位和停止位配置
- 连接后自动发送握手帧并启动 100 ms 心跳，不覆盖设备的监视模式
- 所有页面常驻显示位置、多圈、单圈、速度、电流、母线电压和参数监视值
- 顶部显示使能、故障和驱动模式，底部常驻显示跟随 `Pn002` 的参数监视与实时反馈
- 读取设备 `Pn000`–`Pn199` 全部参数
- 参数页以无表头多列紧凑网格显示 Pn000–Pn199，每列固定 37 项并向下递增，灰色参数编号与可编辑数值明确区分
- 驱动器信息页集中显示通信架构、控制模式和关键标定参数
- 电机、制动器、限定与再生电阻使用独立配置页，并提供参数含义和风险提示
- 回零页内置参考版轨迹图和 Index/限位开关说明
- 故障页内置 45 条参考错误码、说明与处理办法检索
- 数字 I/O 页展示输入/输出功能、有效电平和端子映射
- 反馈页支持 21 种编码器、绝对位置清零、磁极检测和等价编码器输出
- 电流环、速度环、位置环拥有独立参数页和确认写入流程
- 驱动模式页集中配置模式、三类控制环、脉冲输入和位置齿轮
- 参数复位页提供确认保护并发送参考复位帧
- 参数工作台和备份恢复页使用参考程序兼容的 `PnNNN 原始值` TXT 格式
- 制动、反馈和故障页补齐参考时序图、波形图和逻辑图
- 应用配置页支持启动画面、默认页面和界面语言设置
- 关于页显示程序版本与当前 Qt 运行版本
- 驱动器信息页支持参考电压/电流规格选择并写入 `Pn021`
- `Pn169` 十进制符号位编码与解码
- 参数 TXT 导入和导出，导出时可选择目录并编辑文件名
- 位置、多圈、单圈、速度、电流、母线电压、参数监视实时卡片
- `P+PCMD`、`V+VCMD`、`I+ICMD` 可按监控组一键选择并互斥其他通道，PE 和参数监视可单独监控，
  支持 X/Y 轴放缩、时间窗口设置、Y 轴 Auto/Manual 和监控数据 CSV 导出
- 示波页采用左侧显示控制、中间波形与运动/性能参数选项卡、右侧通道及坐标轴设置布局
- 每条示波通道可单独设置偏移 B 和增益 K，显示值为 `原始值 × K + B`，默认 `B=0、K=1`
- 串口批量帧先完整入队，再按 2 ms/帧节奏连续播放；曲线使用 OpenGL 和 5 ms 增量重绘
- 选择 `X-Zoom` 或 `Y-Zoom` 后可用滚轮缩放对应轴；X-Zoom 下支持左键拖拽平移，双击绘图区或点击复位可显示完整波形
- 波形可保存为带版本头的 CSV，读取时恢复原始采样、通道显示、K/B、单位和时间窗口
- 波形图按 10 个纵向区间显示网格，鼠标悬停显示吸附到采样时刻的竖向指示线、时间及各显示通道数值
- X 轴时间长度输入使用整数秒，波形 X 轴刻度和悬停时间保留毫秒；数值按通道真实精度显示，电流保留两位小数，位置和速度保持整数
- 示波器默认显示最近 10 秒；全局复位只恢复波形缩放，不修改用户选择的 X 轴时间长度
- 遥测数据只按接收帧实时记录，中间值不会被最新值覆盖或人为补点；图表以 10 ms 周期刷新
- 全部页面底部使用单行参数监视带
- 顶部状态标志靠左显示，不重复显示当前页面标题
- 电机使能、安全停止、故障复位和参数保存快捷命令
- 原始十六进制通信日志和自定义帧发送
- 通信日志按 8 字节一帧分行显示，并实时统计 RX/TX 字节吞吐速度
- 参数写入、EEPROM 保存和退出前的安全确认

## 代码结构

| 文件 | 职责 |
|---|---|
| `deviceserialservice.*` | 串口生命周期、心跳、帧收发、参数与遥测解析 |
| `parametercatalog.*` | Pn 参数定义、分组及 Pn169 编解码 |
| `parametermodel.*` | 200 项参数表、修改跟踪、TXT 备份恢复及旧版 CSV 导入 |
| `dashboardpage.*` | 实时状态卡片和设备快捷操作 |
| `parameterpage.*` | 按列递增的多列参数网格、单参数回车写入和 TXT 导入导出 |
| `monitorpage.*` | 实时逐帧曲线、鼠标测量、双选项卡和坐标轴控制 |
| `communicationpage.*` | 串口设置、设备命令和原始通信日志 |
| `driveinfopage.*` | 驱动器身份、关键参数与通信架构概览 |
| `deviceconfigpage.*` | 电机、制动、限量和再生电阻的通用参数表单 |
| `homingpage.*` | 回零方法、轨迹图和文字说明 |
| `faultpage.*` | 参考错误码字典和故障状态 |
| `digitaliopage.*` | 数字输入/输出功能与端子映射 |
| `feedbackpage.*` | 编码器、位置清零、磁极检测和等价输出 |
| `docs/KaiserStudio_Reference_Analysis.md` | 参考程序逐页功能和中文说明分析 |
| `preferencespage.*` | 启动画面、默认页面和语言选项 |
| `aboutpage.*` | 程序版本、Qt 版本和用途说明 |
| `mainwindow.*` | 页面编排、业务确认和模块连接 |

旧版 EHA 自动标定界面保留在仓库历史及未参与构建的旧文件中，新分支以通用驱动器
调试工作台为入口。

## 构建

建议使用 Qt 5.15.2 MinGW 64-bit：

```powershell
cmake -S . -B build/KaiserStudio-Qt5-Release -G Ninja `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_PREFIX_PATH=C:/Qt/5.15.2/mingw81_64 `
  -DCMAKE_MAKE_PROGRAM=C:/Qt/Tools/Ninja/ninja.exe
cmake --build build/KaiserStudio-Qt5-Release --parallel
```

构建产物为 `build/KaiserStudio-Qt5-Release/KaiserStudio.exe`。
